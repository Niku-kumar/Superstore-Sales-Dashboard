# Superstore Sales Dashboard & Forecast

## 📊 Project Overview

This project is an interactive Power BI dashboard created using the Superstore dataset.

The dashboard provides insights into sales, profit, orders, regions, categories, 
shipping modes and state-wise performance.

It also includes a 15-day sales forecast to analyze expected future sales trends.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## 📈 Dashboard Features

### Sales Dashboard

- Total Orders
- Total Sales
- Total Profit
- Average Ship Days
- Sales by Payment Mode
- Sales by Region
- Sales by Segment
- Sales by Month
- Profit by Month
- Sales by Ship Mode
- Sales by Category
- Sales by Sub-Category
- Profit and Sales by State

### Sales Forecast

- Historical Sales Trend
- 15-Day Sales Forecast
- Forecast Confidence Interval
- State-wise Sales Analysis

## 🎯 Key Insights

- Technology and Office Supplies contribute significantly to overall sales.
- Consumer segment has the highest contribution.
- Standard Class is the most commonly used shipping mode.
- Sales show noticeable fluctuations across months.
- The forecast provides an estimate of future sales for the next 15 days.
